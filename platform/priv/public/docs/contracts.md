## OpenAPI

The [OpenAPI JSON specification]({{origin}}/openapi.json) describes the health reads, the product directory, published Reading content, the owner-authorized claims and stake reads, agent pairing and every signed agent read, with their schemas, sign-in needs and request limits. It does not describe wallet transactions or session changes.

The [YAML contract]({{origin}}/api-contract.openapiv3.yaml) describes agent pairing, the signed agent reads and the browser sign-in session; every operation it lists is live.

## Versions

The API changes in place and these docs change the same day; no old versions are kept. [Changes]({{origin}}/docs/changes) lists each change.

The published [@regentslabs/cli package](https://www.npmjs.com/package/@regentslabs/cli) version 0.5.0 was built against an earlier version of this service and does not work with it. Use the requests in these docs, or regents-cli as [Pairing]({{origin}}/docs/pairing) shows.

## Other products

Each product owns its own permissions and integration contract. For token auctions use [Autolaunch](https://autolaunch.sh); for Skill evaluations, [Techtree](https://techtree.sh); for agent-tool reports and repairs, [Patchbay](https://patchbay.help).
