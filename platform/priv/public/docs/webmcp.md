## Tools

Every page offers these tools to browsers that support WebMCP (`document.modelContext`). They make the same requests as the API and never open a wallet or sign. Each reads, except `messages_leave`, which leaves a private message for the Regents team. Private browser tools need the agent's own fresh SIWA proof and current pairing; the owner's browser session grants no agent authority.
